# Crypto Dashboard

Web application that uses the CoinGecko API to analyze cryptocurrency data.

## The application allows users to:
- compare prices of multiple cryptocurrencies across different time periods
- track market cap and total trading volume
- visualize historical data on interactive charts
- compare up to 5 cryptocurrencies simultaneously

## Tech Stack:
- TypeScript
- React (v19.2)
- Vite (v7.3)
- Axios
- Material UI
- Recharts
